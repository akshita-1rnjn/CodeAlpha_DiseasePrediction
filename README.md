# Disease Prediction from Medical Data

## Project Overview

This project predicts whether a patient is likely to have diabetes using Machine Learning techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## Machine Learning Algorithm

* Logistic Regression

## Dataset

Pima Indians Diabetes Dataset

## Features

* Data Loading and Preprocessing
* Model Training
* Disease Prediction
* Accuracy Evaluation

## Result

The model achieved approximately 75% accuracy in predicting diabetes based on patient health data.

## How to Run

1. Install required libraries:
   pip install -r requirements.txt

2. Run the program:
   python disease_prediction.py
